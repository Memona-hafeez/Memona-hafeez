business workflows. My work spans retrieval-augmented generation, document
intelligence, multi-agent systems, voice applications, and production APIs.

retrieval quality, structured outputs, clear failure handling, and deployments

## Featured work

### [QRShield](https://github.com/Memona-hafeez/QRShield) · Security research

An end-to-end QR security system that checks both sides of a QR threat:
tampering in the image and maliciousness in the decoded URL. The project combines
image analysis with URL classification trained on a public malicious-URL dataset.
The manuscript is prepared for *IEEE Access*.

### [LinkedIn Comment Generator](https://github.com/Memona-hafeez/Linkedln_comment_generator-fined_tuned_GPT_4o_model-) · Client delivery

A production application using a fine-tuned GPT-4o model and hybrid retrieval to
generate comments that match a post's context, tone, and writing style. Deployed
on Render with Firebase-backed user history.

### [Podcast Audio Intelligence](https://github.com/Memona-hafeez/Youtube_transcriber_vedio_audio_podcast_QA_rag_system) · AI application

FastAPI services for Whisper transcription, topic extraction, speaker
identification, and question answering over podcast content.

### [HealthHub AI](https://github.com/Memona-hafeez/HealthHub-AI--Multi-Specialist-Healthcare-Assistant) · AI application

A multi-specialist healthcare assistant using retrieval over structured healthcare
data to provide focused responses for different medical domains.

### [Ollama RAG Chatbot](https://github.com/Memona-hafeez/Ollama-RAG-Chatbot-Document-Based-AI-Assistant-) · Open source

A document-based assistant that runs with local models through Ollama and provides
conversation memory through a Streamlit interface.

### [Trip Advisor Agents](https://github.com/Memona-hafeez/AI-Agents-Trip-Advisor) · Agent workflow

Specialized itinerary, budget, weather, and culture agents coordinated into one
travel-planning workflow.
