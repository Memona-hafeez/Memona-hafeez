## Selected work

### QRShield — security research

<a href="https://github.com/Memona-hafeez/QRShield">Repository</a>

QRShield analyzes both parts of a QR-based threat: whether the QR image has been
tampered with and whether its decoded destination is malicious. The project
combines image analysis with URL classification trained on a public malicious-URL
dataset. The manuscript is prepared for *IEEE Access*.

### LinkedIn Comment Generator — client delivery

<a href="https://github.com/Memona-hafeez/Linkedln_comment_generator-fined_tuned_GPT_4o_model-">Repository</a>

A production application using a fine-tuned GPT-4o model and hybrid retrieval to
generate comments that match a post's context, tone, and writing style. Deployed
on Render with Firebase-backed user history.

### Podcast Audio Intelligence — application

<a href="https://github.com/Memona-hafeez/Youtube_transcriber_vedio_audio_podcast_QA_rag_system">Repository</a>

FastAPI services for audio transcription with Whisper, topic extraction, speaker
identification, and question answering over podcast content.

### HealthHub AI — application

<a href="https://github.com/Memona-hafeez/HealthHub-AI--Multi-Specialist-Healthcare-Assistant">Repository</a>

A multi-specialist healthcare assistant using retrieval over structured healthcare
data to provide focused responses for different medical domains.

### Ollama RAG Chatbot — open-source project

<a href="https://github.com/Memona-hafeez/Ollama-RAG-Chatbot-Document-Based-AI-Assistant-">Repository</a>

### Trip Advisor Agents — agent workflow

<a href="https://github.com/Memona-hafeez/AI-Agents-Trip-Advisor">Repository</a>
